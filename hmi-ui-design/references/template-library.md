# 可复用模板、公共素材与增量缓存

内置清蓝总览、石墨参数、暖灰报警趋势三套1024×600布局/配色，保留独立组件源与离线HTML。`assets/template-library/library.py`是共享组件和布局源；模板是起点，不把三页固定成所有项目默认。

这三套旧实例用于复用素材/组件，不是新项目默认方案的数量。新项目按[默认布局规则](default-layout-rules.md)提供左侧/底部导航及四种独立色调，并按目标屏幕调整信息容量；默认方向配置见style-catalog.json与style-proposal.template.json。实际MCGS交付仍从同一项目源生成可编辑/可复制会话，不能将方向示例当作另一套整页内容维护。

V2.11 test5的原生路径支持[七种分辨率](resolution-adaptation.md)，本库三套示例的源布局仍为1024×600。其他尺寸复用主题及组件后按实际空间重新布局、构建新会话；现有模板构建命令不会自动生成七套布局，也不应只改画布数字或拉伸整页。

## 先确定业务，再挑复用起点

新项目先按 [需求引导](design-intake.md) 确定行业、设备用途、工艺和操作任务，再选本库适用部分。直接运行下方示例会产生演示页，不能把演示页标题/数据直接当作客户的内容策划或首轮引导。

| 复用层 | 可以沿用 | 随项目调整/新增 |
|---|---|---|
| 原生结构 | 12类类型、序列化和已开放字段 | 用途、数量、几何、文案、样式与绑定方式；未实现动态属性单列缺项 |
| 设备素材 | 相符的独立母版、端口与状态层 | 外形、型号特征、视角/风格、工艺组合及新设备母版 |
| 布局与主题 | 公共框架、主题槽位和组件家族 | 页面分区、导航、内容密度、配色和新布局；不限三套样板 |
| 页面内容 | 合适的任务配方 | 本行业数据/单位、设备关系、状态与操作；不固定为三页 |

12类控件不等于12种固定皮肤；通用SVG/图标/设备图可新增并以独立图片承载，原生动态部分仍使用相符类型。不要把动态内容画成静态图来冒充支持。

在项目需求/内容计划记录复用源ID/版本、匹配依据、修改项、新增项和实例引用。跨行业可复用匹配的泵/阀等结构，同一行业也可能需要不同母版。已有源在结构、状态、端口、尺寸和风格匹配时直接用；不匹配只改相关层或新增，不为缓存命中保留错误设备，也不为换色重画整页。

模板构建器是样板工具。超出其槽位时修改项目组件模型/渲染源并检查结果，不能只改模板名称或把复杂页面降级成总览。

## 复用后的项目源

MCGS新项目用[同源构建](shared-project.md)维护组件和变量，按**复用模板资产 → 一份项目源 → 代表页验证 → 展开全套**交付。示例模板可提供素材/布局起点，但不能直接替代客户的内容清单。新增设备保留源ID/版本、结构/端口/状态与实例映射；每页字段用同一数据定义，网页与原生输出不再手写两份内容。图标可用图片工厂，不能以12类没有“图标”类别为由删除。

复用对象包括控件类型及已支持字段、变量引用、皮肤/图片、稳定组件ID和布局/主题；把这些在权威源中项目化后直接交付可编辑、可复制会话。增加设备数量、组件数量或更换分辨率时扩充源层，不因样板槽位不足而先另写一套完整HTML。外观和业务可自由新增。模板模型与项目源的区别及迁移规则见[单一交付入口](shared-project.md)。

## 构建样板与缓存

运行`python scripts/build_template_previews.py --out 项目/templates`即可建立实例，命令不需要MCP、供体或工程profile。按本项目修改标题、页名、变量、业务内容和独立revision，再建立[局部编辑会话](local-editor.md)。预览阶段即可复制；正式通用素材包另行按需生成。

构建模板时同样先运行统一字体测量与扩框检查，离线HTML及原生会话共用适配后的矩形。碰撞或越界时报告并停止该模板输出，不绕过复制前的字号检查。

网页以SVG全文、目标宽高和渲染版本计算SHA，优先查内存/IndexedDB；位置或文字改动不重画未变化图片。项目asset-cache按PNG内容SHA复用存储，每次导出保留逐实例归属与校验。不得为了缓存把原生文字、数值或多个组件合并进图片。

新环境检查使用`python scripts/check_editor_portability.py --out 项目/新环境检查`，在全新中文/空格目录独立运行，检查内置代码与结构、模型、变量隔离及复制数据生成，不依赖另一任务的缓存、目录、服务或原生适配包。Windows、Python、Pillow为复制运行依赖，不需要另一份MCGS工程skill、Jet或MCP。

未绑定默认模式与名称待编译模式都不能记为业务运行已完成。新窗口无原工程保护数据的中性化分支、导航名称解析和名称绑定编译需要实际原厂验证；本机目录检查不代表另一台电脑已通过。
