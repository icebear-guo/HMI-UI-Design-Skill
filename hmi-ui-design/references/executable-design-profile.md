# 面向已验证工程工具的设计

1.06接口修订按[MCGS接口兼容说明](mcgs-interface-compatibility.md)执行。代表页先用execution_profile.py --spec预检，无需提前生产PNG。当前瞬时按钮仅local_demo；按钮内部caption按整按钮框布局，水平left/center、垂直top/center须明确填写。其他设计保留并列待适配，不外置文字兜底；通用profile不是实际模板证据。

作者备注：工控北极熊（抖音）。

MCGS项目先读取工程侧版本化execution_profile与本次实际模板的供体证据，再设计代表页；通用工具配置不能替代模板证据。供体类型存在不等于所有属性已适配。默认使用可直接调用的工具组合，未知能力先完成代表组件适配；不要求执行模型在最终交付时临时逆向字段。

当前自动数值核心：居中、padding=0、背景透明、原生边框/图片关闭。底板/边框/阴影独立布局组件，数值核心按布局定位；输出单位用独立原生标签，输入单位可按明确支持路径内嵌或独立。需不同排版时先给工程侧验证专用适配，不能在写入时静默改版。此配置只约束当前自动工具路径，不是其他平台或MCGS的固有上限。

当前自动按钮行为用明确的navigate或local_demo范围momentary结构。HTML导航给data-hmi-target，瞬时请求给data-hmi-action="momentary"，交付仍写完整interaction及变量/取值。custom仅用于有独立工程规格的特殊行为，不能将普通瞬时请求写成一句custom说明来绕开字段契约。

源树必须覆盖所有实际可见绘制。单纯div.panel、整页CSS背景或未登记SVG管网不会因为没有data-hmi-component就自动变成“可省略”。给背景、布局、管道/箭头等实际语义组件建立ID、角色、页归属与导出去向；背景组件仅绘制自己的底色/纹理，不包整页前景。render_components的visual_coverage列出组件外可见绘制，在preview时修正，确认前保持可编辑。

独立机械母版内部的渐变、轮廓、螺栓等可以属于母版绘制，组件源仍可编辑；灯、标签、动态值、独立装饰与布局语义继续分层。所有可见源→合法资产/原生对象对账，不把最低合同数量当完整覆盖。
