# 完整 UI 设计交付标准

用户要求完整设计交付时，提交可解压、离线操作的HTML原型与设计标注包，不能只给截图、标注热区、提示词、说明文档或一张拼图。用户明确只要求规范、提示词、局部修改或评审时，按指定范围交付。

首次方向未定时，先按 [需求与打样流程](design-intake.md) 交付同一代表页的多方案HTML和待选择记录，选定后再展开完整包。方向样例不要求提前完成所有页面、切片或未知工程功能，不能将其宣称为最终交付。

## 目录与文件

```text
hmi-ui-delivery/
├─ index.html                 离线功能原型与设计标注入口
├─ preview/                   完整页面 PNG 预览
├─ assets/                    可直接取用的独立 PNG 切片
├─ fonts/                     可随本次交付提供的字体，或缺失说明
├─ specs/design.json          页面、图层、逻辑坐标与组件信息
└─ manifest.json              文件清单、实际尺寸记录与校验信息
hmi-ui-delivery.zip            与目录内容一致的压缩包
```

页面和切片数量以任务实际范围为准，不固定某个数量。目录名、文件名、示例和界面标题使用通用功能命名。原始可编辑源文件若确实存在，可另行附带并说明格式；没有时不得声称已提供。

## 离线标注入口

- 解压后打开 `index.html`，无需登录、网络、CDN 或本地服务。
- 默认进入交互演示，可切换设计标注。按 [功能原型规范](interactive-preview.md) 实现当前画面的按钮、灯/IO、输出模拟强制、导航、参数键盘、仪表及棒图适用项；不能用属性区按钮演示替代整页交互。
- 可以切换页面、缩放预览、显示/隐藏标注框，点击或选择图层查看逻辑 x/y/w/h、名称、类型、文本、字号/字重、字体与填充色等已知字段。
- 标注框按设计坐标定位，预览像素倍率单独显示；切换缩放后命中区域仍与画面一致。
- 可浏览和下载独立资产、查看状态编号与组件归属、读取字体资源清单。
- 新设计的每个按钮至少提供 `s0` 常态和 `s1` 交互反馈两片，同画布、同锚点，并有可辨识的按下变化。瞬时按钮按下切到s1、释放回s0；导航/切换若采用持久选中态，须另外明确语义和恢复规则，不能冒充设备执行结果。
- 未提供的属性显示“未提供”，不能根据截图补造图层、字体、控制逻辑或工程绑定。

## 预览、切片与字体

完整页预览与设计画板比例一致，记录逻辑尺寸、真实 PNG 像素和倍率。独立切片保留其实际像素，同一组件状态组保持相同画布；切片状态编号不自动变成设备语义。页面文字与运行数据的实现仍按原生控件/可编辑层规则处理。

设计标注模式在属性区提供独立按钮底板预览，整页保留原图加选层框；功能交互模式在画面内渲染可操作组件，底板与文字分层，动态数值独立绑定。两种模式均不补造未知工程信息、不发送设备命令。机械检查确认两片存在、画布一致且解码后的RGBA像素不同，拒绝同图改名或改编码冒充双态；可辨识性、锚点及底板覆盖仍需看图验收。

字体只在有明确随交付提供权限时复制，不自动安装。没有可提供的字体文件时保留字体清单说明，并注明目标平台需要确认的字体或回退方案。禁止为填满目录而拷贝不明字体。

## 构建助手

`scripts/build_delivery.py` 只打包已经存在且校验通过的 PNG、显式图层数据和许可字体，不生图、不切片、不重绘、不恢复压平图层。依赖 Python 3.12+ 与 Pillow。输入为 UTF-8 JSON；路径相对 manifest 所在目录，禁止绝对路径、越界、链接与非法路径。

```powershell
python .\scripts\build_delivery.py --manifest .\delivery-manifest.json --out .\exports\hmi-ui-delivery
```

`--out` 的父目录必须存在，目标目录和并列 `.zip` 必须均不存在；已有交付不覆盖。构建前验证输入和全部页面/图层边界；构建后对复制文件核对哈希。普通读写失败会清理本次新建输出，外部进程同时改动或强制终止不具备事务保证。

### 输入契约 1.1

根字段：`schema_version="1.1"`、非空 `pages`、非空 `assets`、`simulation`；`fonts`可省略。simulation中的变量、适用交互和图层行为契约见 [功能原型规范](interactive-preview.md)。1.0仅兼容旧标注包，不能称为当前完整UI交付。缺少实际页面、切片或功能原型时先补齐或明确报告缺口。

| 对象 | 必填字段 | 可选字段/约束 |
|---|---|---|
| page | `id,name,design_size_px,preview,layers` | layers非空；preview为真实静态PNG |
| layer | `id,name,type,rect_px` | `text`、`fill="#RRGGBB"`、`font`、`interaction`；功能组件必须有text及interaction；矩形为逻辑 `[x,y,w,h]` |
| font属性 | `family,size_px` | `weight` 为100–900整数或normal/bold；只记录已知信息 |
| asset | `id,file,component_id,state,design_size_px` | file为独立PNG；同组件状态唯一且设计/实际画布一致 |
| font资源 | `file,usage_allowed=true` | `family`可选；格式ttf/otf/woff/woff2，显式许可后才复制 |

ID/组件ID使用小写ASCII字母、数字、连字符或下划线；页面ID、资产ID各自唯一，图层ID在各页面内唯一。尺寸为有限正数，矩形原点非负；不允许画面越界或非等比图像。输出文件用这些安全ID重命名，保持组件映射。

`layer.type` 为 `button` 或 `control` 时，必须有 `component_id=layer.id` 的 `s0` 和 `s1` 资产，两片设计尺寸均等于该图层矩形宽高。该约束用于新设计的按钮交付；接手未知旧状态时应先完成明确映射，再制作符合新规范的交付，不把未知编号伪称已实现按钮反馈。

## 验收与交付

交付前检查 HTML 是否能离线操作、声明的功能是否实际实现、页面/独立文件是否完整、选层/缩放及字体参数是否准确，以及ZIP解压结构。按 [交互验收动作](interactive-preview.md) 检查瞬时复位、强制解除、导航目标、参数校验和仪表/棒图绑定。对文件/像素/纯逻辑、浏览器实际操作、目标平台导入分别记录结果；构建成功不等于浏览器交互、设备运行或现场验收已通过。

构建后执行 [自动验收](automatic-acceptance.md)，输出机器可读报告。文件与纯逻辑检查不需要用户手工逐项操作；完整范围的浏览器或现场检查受阻时，报告保留未完成项，不用模拟测试替代真实界面验收。
