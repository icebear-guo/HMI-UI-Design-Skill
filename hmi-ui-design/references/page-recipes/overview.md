# 运行总览内容配方

ID：overview；版本：1.0.0；状态：建议。只纳入设备适用且C1确认的模块。

**主要任务**：迅速判断当前对象、设备是否可用、哪些量值得关注，以及下一步进入哪里或执行什么操作。

| 优先级 | 内容模块 | 内容与表达建议 |
|---|---|---|
| 核心 | 对象与状态 | 设备/工位名、模式、状态灯及文字；通信与质量来自公共框架 |
| 核心 | 关键工艺量 | 按任务挑选数值、单位、目标/范围和质量；如速度、温度或压力，仅在适用时采用 |
| 按任务 | 主操作 | 适用的启动、停止、复位等；目标、允许条件、按钮反馈与执行结果区分 |
| 按任务 | 生产/任务摘要 | 今日或本班数量、目标、班次/时段；非生产设备用自身任务指标替代 |
| 可选 | 设备/工艺简图 | 显示实际相关单元和流向，支持定位；没有结构依据时不虚构复杂管线 |
| 可选 | 变化与诊断入口 | 近期小趋势、关注项、报警/维护入口；避免与报警带重复堆叠 |

**布局建议**：对象/工艺与操作分区；关键工艺量相邻成组，单位与数值靠近；生产摘要作为辅助。不要以巨大标识、空设备图或重复仪表代替内容。空间不足时保留当前状态与关键量，再调整辅助摘要。

**HTML样例**：本地启动/停止演示包含s0/s1按下与释放；独立模拟反馈更新状态灯/文字。数值驱动对应仪表或棒图（若使用）。顶栏失联时，同一对象的读数标示质量，不能仍称实时正常。命令、状态与质量不能由一次点击无条件一起变成成功。

**内容检查**：能从当前页回答“什么设备、什么模式、是否可信、关键量多少、下一步做什么”。模拟值、工艺范围和工程未知项明确分开。
