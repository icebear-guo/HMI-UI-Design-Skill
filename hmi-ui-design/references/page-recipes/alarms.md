# 报警记录内容配方

ID：alarms；版本：1.0.0；状态：建议。优先级与确认/恢复策略由项目定义。

**主要任务**：发现当前问题、定位对象、了解时间与处理状态，查看历史和必要详情。

| 优先级 | 内容模块 | 内容与表达建议 |
|---|---|---|
| 核心 | 当前/历史范围 | 清楚标明正在查看活动报警还是历史，显示数量与筛选条件 |
| 核心 | 报警表 | 时间、对象、可理解的描述、优先级及活动/确认/恢复状态 |
| 核心 | 详情 | 所选记录的完整内容、发生/恢复时间、已知处理入口 |
| 按任务 | 筛选与确认 | 对象、时间或级别筛选、清除筛选、模拟确认；按项目策略决定是否可确认 |
| 可选 | 事件/导出 | 报警以外的操作事件或记录导出，只有实际实现时标为可用 |

**布局建议**：表格是主区，筛选在固定可辨位置，详情不遮挡所选对象。长描述可展开；颜色之外保留优先级和状态文本。公共报警带与当前表数据一致。

**HTML样例**：提供合成活动、已确认未恢复、已恢复记录及无结果空态；筛选改变实际可见行，详情对应所选记录。模拟确认只修改确认状态，不自动清除故障或删除历史。未实现文件导出时不做伪下载按钮。

**内容检查**：当前报警与历史不混淆，确认和恢复可区分；不能只用几张红色卡片代替报警记录。
