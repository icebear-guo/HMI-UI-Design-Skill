# 手动操作内容配方

ID：manual；版本：1.0.0；状态：建议。操作对象和动作来自本次设备范围。

**主要任务**：选中正确对象、了解动作条件，执行可用的手动操作并观察反馈。

| 优先级 | 内容模块 | 内容与表达建议 |
|---|---|---|
| 核心 | 对象选择与模式 | 单元/执行器名称、选中对象、当前模式；不只显示无对象的启停按钮 |
| 核心 | 动作与反馈 | 按对象配正/反转、开/关、伸/缩或点动等适用动作，标签明确目标 |
| 核心 | 操作条件 | 允许/不允许、已知条件/联锁及原因；未知工程条件标待确认 |
| 按任务 | 位置/工况 | 当前位置、到位开关、速度或压力等实际相关反馈 |
| 可选 | 操作事件 | 当前请求、等待/拒绝/超时及最近模拟动作记录 |

**布局建议**：左侧或上方明确对象，动作与对应反馈相邻；互斥动作成组但热区不相交，禁止条件在操作附近可见。多个对象使用可理解的分组/列表，不挤成无标签按钮墙。

**HTML样例**：所有动作按钮有s0/s1。若项目选择按住点动，释放、取消、失焦和切页停止本地模拟请求；若为一次请求，单独表达等待与反馈。模拟条件不足时说明原因，不能灰掉按钮却无解释。未提供真实控制逻辑时，不擅自赋予可上机的联锁或安全能力。

**内容检查**：每个动作都有目标、条件、触发方式和结果显示；不让“手动”页面与总览只有标题差异。
