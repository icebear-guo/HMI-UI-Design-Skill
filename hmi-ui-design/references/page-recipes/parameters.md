# 参数设置内容配方

ID：parameters；版本：1.0.0；状态：建议。实际参数名、范围与精度来自工程；未知时使用标明模拟的数据。

**主要任务**：找到需要的参数，理解当前值与拟修改值，校验后提交或取消。

| 优先级 | 内容模块 | 内容与表达建议 |
|---|---|---|
| 核心 | 参数分组/列表 | 组名、参数名、读取值、单位、可编辑性 |
| 核心 | 编辑与约束 | 编辑值、范围、精度/步长，输入入口与数值键盘 |
| 核心 | 提交结果 | 待修改标记、确认/取消、校验错误或等待/拒绝；读取值和编辑值分开 |
| 按任务 | 身份与条件 | 当前权限、可否修改、何时生效及已知前置条件 |
| 可选 | 配方/传输 | 名称、读取/下发方向、覆盖对象与结果；仅项目要求时加入 |

**布局建议**：参数表为主，名称、当前值、编辑值、单位对齐；键盘不遮住正在编辑的对象/约束。需要滚动时保持字段含义清晰。不要改成几个不能输入的指标卡。

**HTML样例**：点击编辑入口打开键盘，支持小数/正负号等适用输入、删除、越界和格式校验、确认及取消。取消不改变已提交值；确认更新本地模拟值和关联仪表（若有），明确是模拟。工程端回读与生效规则未知时，不伪造真实写入成功。

**内容检查**：能识别改了什么、未提交什么、为什么不能提交、最终显示什么；范围和单位始终可见或可直接查阅。
