# IO监控内容配方

ID：io；版本：1.0.0；状态：建议。实际通道与质量定义来自工程。

**主要任务**：定位通道、读懂数值/质量，区分原始值与输出强制状态。

| 优先级 | 内容模块 | 内容与表达建议 |
|---|---|---|
| 核心 | 类型/对象选择 | DI、DO及适用AI/AO，所属单元、通道数量、筛选 |
| 核心 | 通道清单 | 通道ID/地址、名称、值、小灯/数值、质量，不把灭灯等同通信正常 |
| 按任务 | 输出来源 | 基础值、有效值、自动/模拟强制ON/OFF，醒目标示强制对象 |
| 按任务 | 强制操作 | 本地模拟强制ON、OFF、解除，权限/模式与说明 |
| 可选 | 模拟量 | 工程值、单位、量程及质量；原始值仅在任务需要时显示 |

**布局建议**：按对象和类型成组，用通道行或网格稳定对齐；输入与输出可区分，强制状态紧贴对应通道。超出当前容量合理滚动/分页，不无限缩小灯和文字。通道ID和名称不能只靠悬浮才看到。

**HTML样例**：点击允许演示的输入通道切换本地模拟值，灯与文字一致；输出可强制ON/OFF并解除，解除恢复基础模拟值。断线/未知单独表达，强制来源不被值相同掩盖。真实工程的强制权限与操作条件不从演示推定。

**内容检查**：可找到具体通道、读懂输入/输出与质量，知道哪些值被强制；小灯各状态及图标均纳入后续资产盘点。
