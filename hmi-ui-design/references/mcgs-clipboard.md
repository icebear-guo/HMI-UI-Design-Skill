# MCGS唯一出口：HTML原生复制粘贴

MCGS只通过复制粘贴接入，不再提供兼容素材、handoff字段包、离线MCP写入或MCGS导出选择。通用SVG/PNG/文字/布局素材独立交付。HTML预览、局部编辑和复制可在设计阶段使用，不被最终素材包流程阻塞。

skill内置12类中性原生默认结构与序列化器，直接从项目模型生成新控件/窗口。默认结构源自已标定格式的中性化默认值，不是仅有一份字段说明，也不依赖运行时读取旧工程。它不宣称能够从任意版本/未知布局推断所有默认值。

默认复制未绑定控件，数值显示使用常量0占位；保留可选名称绑定模式，需MCGS校验/编译。当前页面导航名称需在MCGS解析，未解析编号不是实际工程ID。详情见[局部编辑](local-editor.md)。

图片使用真正图片控件；读数用数值显示，输入用数值输入，位命令用位状态按钮，导航用标准导航按钮。文字、读数和按钮caption保持原生归属；数值专属皮肤生成内置图片，共享卡片独立，不压成整页图片。各态子项的local/parent/float坐标分别同步。

Windows业务格式按名称注册，不固定数值格式ID；仅发布上述两个MCGS格式，不重放OLE指针。助手仅绑定127.0.0.1，校验Host、Origin、会话令牌、模型版本、选中对象和已知字段。写前检查剪贴板序号，写后回读全部字节与SHA。

同源SVG按所选组件和实际尺寸即时转PNG，优先命中组件缓存。未选中图层不进入局部复制，不因为准备复制而批量导出全套素材。源SVG可继续编辑，MCGS内图片对象不等于可编辑其矢量轮廓。

只读写本轮项目会话与剪贴板，不读取或修改MCP。字段解析/内存回环/剪贴板回读与原厂保存/组态/编译/运行分别验收；不将旧供体分支的通过结果写成本版中性结构已经全部通过。
