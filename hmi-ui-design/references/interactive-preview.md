# 可交互 HTML 原型

完整 UI 设计必须交付可离线操作的 HTML 原型及设计标注。整页截图、透明热区只弹标注、属性区单独切换按钮图片，均不能替代画面内的功能交互。仅要求规范或单项素材时不扩充交付范围。

## 按画面功能实现

| 组件 | 可操作行为 | 验收动作 |
|---|---|---|
| 瞬时按钮 | 画面内按下为s1，松开为s0；本地请求量按下为1、松开为0 | 鼠标、触控、空格/回车；取消、失焦、切页、页面隐藏后不残留按下量 |
| 保持切换 | 点击切换布尔值，独立显示ON/OFF和选中语义；s1仍只是按下反馈 | 连续点击与键盘切换，跨页保留值，重置恢复初值 |
| 指示灯、输入IO | 点击切换本地输入量；灯色与ON/OFF文字一致 | 检查0→1→0，同一变量的其他组件同步变化 |
| 输出IO | 本地自动值与强制值分开；支持强制ON、强制OFF、解除强制 | 强制时改变自动值不改变有效输出；解除后跟随当前自动值；明确显示模拟强制状态 |
| 导航 | 切换到目标画面及其真实内容，更新当前页标识 | 检查每个目标存在且能返回，不能只变按钮颜色 |
| 参数 | 点开数字键盘，也允许键盘输入；显示范围、步长和单位 | 确认写入本地变量；取消不写入；拒绝空值、非数值、越界、不合步长；支持负数、小数及退格 |
| 仪表 | 指针、读数和范围绑定同一数值 | 最小/中间/最大值一致，数值变化时指针移动 |
| 棒图 | 横/竖填充比例和数值绑定同一变量 | 检查0%/中间/100%的映射与动作，不以静态图片冒充动态棒图 |

按任务确定适用组件；画面存在某项就实现该项，不为凑齐演示而给实际项目添加无关控制。用户明确要求的组件写入 `simulation.required_features`，不能用“未适用”跳过。缺少真实通信资料时用显式本地模拟变量，禁止编造PLC地址或把模拟反馈称为设备执行成功。

提供重置入口；数值可通过参数、模拟滑块或演示时钟驱动。离开交互模式停止演示时钟并释放瞬时量；禁止让画面退出后仍留下按下命令。参数弹窗应可用键盘确认/取消，焦点留在弹窗并在关闭后返回触发控件。

## 分层与画面一致性

- 标注模式保留整页预览；交互模式在同一设计坐标叠加真正的控件与动态显示，公共状态栏、报警带和导航跨页保持一致。
- 底板s0/s1、图标、可编辑标签、状态指示、热区分别管理。文字独立渲染，切换底板时不能丢字、重复字或把实时读数烘焙在切片里。
- 动态组件矩形应覆盖其预览占位内容；确认底板透明区域没有露出旧数值。带透空的复杂组件应准备干净背景/分层素材，不靠热区掩盖压平稿缺陷。
- 维护模板提供通用行为和位置渲染；按已确定的视觉稿调整样式与组件组合。它是功能起点，不把通用外观当作任意项目的最终视觉稿。
- 原型、切片与结构化数据使用相同ID、坐标和状态映射。模拟强制与正式工程强制的权限、确认及设备反馈需分别定义；此模板只实现前者。

## 交互清单 1.1

使用 [完整示例清单](../assets/delivery-manifest.template.json)。根对象增加 `simulation`：

```json
{
  "variables": [
    {"id":"input-0","type":"boolean","initial":false},
    {"id":"level","type":"number","initial":40,"min":0,"max":100,"step":1,"unit":"%","animate":true}
  ],
  "required_features": ["io-input","parameter","gauge","bar"]
}
```

变量ID小写字母开头，可含数字、连字符和下划线。布尔变量只含id/type/initial；数值变量必须有有限的min/max/step，min小于max、step为正，初值与上界均按min起算对齐步长。`unit`、`animate`可选；animate为true的数值随演示时钟循环变化，不暗示物理模型。

每个需要操作或动态显示的图层增加 `interaction`，并提供显式可编辑 `text`：

| kind | 额外字段 | 图层/绑定 |
|---|---|---|
| momentary、toggle、indicator、io-input、output | `variable` | boolean；可点击图层type为button/control，必须提供s0/s1 |
| navigation | `target_page` | 目标为已有页面ID；无variable |
| parameter | `variable` | number；可点击图层type为button/control，必须提供s0/s1 |
| gauge | `variable` | number；读数与指针联动 |
| bar | `variable`；可选`orientation`为horizontal/vertical | number；默认横向 |

导航也使用button/control与s0/s1。瞬时请求变量初值必须为false，不能同时绑到保持开关。跨页复用同一组件ID时，行为定义必须一致；共享同一变量时值保持同步。未知kind、缺失绑定、错误类型、目标页不存在、缺少显式行为或遗漏required_features均拒绝构建。

构建器打包已提供的图像和显式行为，不从截图猜测控制逻辑。1.0格式只保留旧标注包兼容；没有功能原型，不满足当前完整UI交付要求。自动检查分别报告原型是否提供、可信事件逻辑结果与真实浏览器状态，参见 [自动验收](automatic-acceptance.md)。
