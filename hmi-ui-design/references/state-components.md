# 状态组件与功能使用参考

用于从页面内容计划选择合适的组件，不要求每页堆放全套。状态语义与命令反馈细则见 [设计规则](design-system.md)，本地HTML行为见 [功能原型](interactive-preview.md)。

| 家族 | 建议构成与绑定 | 需要选择的状态/动作 |
|---|---|---|
| 公共身份/对象 | 标识占位、对象名、系统名、用户人形图标与标签、时钟分别管理 | 未登录/已登录/权限不足；演示入口不冒充真实身份认证 |
| 通信质量 | 小灯、连接/断链图标、状态文字、更新时间 | 连接/断线/未知/陈旧按项目区分；切换模拟质量时各页一致，未知时不点绿灯 |
| 设备状态 | 设备图或简图、状态灯、状态文字、模式 | 待机/运行/停止/故障及适用过渡态；状态来自明确模拟变量或真实反馈 |
| 命令按钮 | 底板、图标、标签、热区、反馈区分层 | s0常态、s1即时按下；另有适用的禁用/待回执/失败，点击不直接等同设备成功 |
| 模式/导航选择 | 选择项、选中标记、当前对象/当前页 | 选中保持与瞬时按下分离；导航进入实际内容，模式改变有独立结果说明 |
| 工艺数值 | 名称、当前值、单位、必要范围/目标值、质量文字 | 正常/无效/未知/陈旧/越界；不把无数据显示为0 |
| 参数输入 | 参数名、读取值、编辑值、单位、范围/精度、键盘 | 只读/编辑/待提交/校验失败/等待/结果；支持确认、取消与错误恢复 |
| 指示灯/IO通道 | 通道ID、名称、灯、值、质量，DI/DO类型 | 二值亮/灭与未知分开；模拟切换有文字一致更新；输出另显强制来源 |
| 输出强制面板 | 基础值、有效值、自动/强制来源、操作区 | 本地强制ON/强制OFF/解除，解除后回到基础模拟值；不向真实设备发命令 |
| 仪表/棒图 | 底板/刻度/单位/数值、指针或填充、数据质量 | 同一变量联动、范围端点/越界/无数据；无质量时不画成正常读数；动态部分保留绑定 |
| 报警列表/摘要 | 文本、对象、时间、优先级、活动/确认/恢复状态 | 有报警/无活动报警/历史为空、筛选、详情、模拟确认；确认不等于恢复 |
| 表格/弹窗/空态 | 标题、字段、选中项、操作、关闭/返回 | 空列表/加载或模拟等待/失败/无权限；弹窗关闭或切页不重发动作 |

先为选中的家族定义本项目实际使用的状态集合，不强行画齐所有表中状态。按钮s0/s1是新设计基本要求；设备运行、选中、故障属于其他维度。原型中尚未实现的状态标明范围，不因为列在规范里就宣称可交互。

HTML演示优先用一组显式本地变量贯穿顶栏、总览、参数和IO等相关页面。改动同一变量时，相关数值、灯、标签和仪表保持一致；切页保留约定状态，重置回到已说明的模拟初值。需要演示正常/断线/报警等场景时，可在独立的“模拟场景”面板切换，不把测试工具混入最终操作导航。

最终图形资产包含这些家族实际使用的图标、灯态、底板和装饰子层，不能只输出大按钮。文字/动态值和动态针/填充的实现规格，以及原生例外的确认要求，依 [资产覆盖](asset-coverage.md) 执行。所有正式PNG仍等C1/C2/C3有效确认后再制作。
