# HTML预览中的局部编辑与原生复制

直接从项目模型建立HTML会话，预览阶段即可复制选中控件、整页控件或1～6个完整窗口。不要求先完成流程3或批量导出图片。点击复制时只渲染所选图形/皮肤的必要PNG，文字、数值、按钮和其他动态元件生成原生控件。正式通用素材包按用户需要单独导出。

## 设计入口与启动示例的用途

新设计先完成 [需求引导](design-intake.md) 中行业/设备/任务和页面内容的整理，再用本项目的实际模型建立会话。若用户仅要复制既有页面或测试原生结构，直接使用其已有模型，不重复行业问卷。

下方模板命令演示启动方法，生成的是演示内容，不替代客户项目策划。编辑器和12类结构库负责编辑/复制；布局、主题、设备图形与页面内容仍可由项目源自由设计和扩充。网页仅开放下表所列属性，其他设计变化通过项目模型/素材源更新后检查，不能宣称全部都能在面板编辑。

## 新设计的首选入口

使用[同源项目](shared-project.md)：`build_project.py --source 项目/project.json --out 项目/build-r1 --port 18780 --allow-copy`。一个源生成可编辑模型、原生复制、覆盖报告和可迁移启动器；组件外观和布局可以重新设计。HTML即时复制不等待最终素材制作。以下原始模型入口用于已有模型与工具试验。

## 内置结构与启动

画布、坐标边界和完整窗口按[七种分辨率](resolution-adaptation.md)使用实际宽高。当前面板可编辑控件，不提供整页自动缩放或自动重排；变更项目尺寸时由助手调整源布局、重新构建新会话并检查，不让用户拉伸旧页冒充适配。

V2.11继续携带12类中性原生默认结构、原生窗口默认结构和对应纯Python序列化代码。不读取MCP，不需要外部供体、工程快照、窗口模板或另一份工程skill。默认结构不是任意控件的通用逆向器；只开放当前12类已实现字段，其他类型明确报告缺型。

```powershell
python scripts/build_template_previews.py --out 项目/templates
python scripts/prepare_editor_session.py --pages 项目/templates/pages.json --out 项目/session --template-previews 项目/templates --allow-copy
python scripts/start_editor.py --session 项目/session/session.json
```

模型由本项目显式页面/组件源生成。示例模板只是起点；实际页数、页名、变量、品牌与内容按任务组织，不强制生成三页。Windows、Python与Pillow是复制助手的运行依赖；不需要Jet数据库或MCP读取环境。后台启动使用隐藏窗口，实际检查页面入口可访问再交付。启动器通过会话身份识别已有服务；匹配才复用，不匹配则报告并另选会话端口，不能见到占用就说已启动。已有会话可运行`create_editor_launcher.py --session 会话/session.json --out 新启动包`生成相对路径启动器和项目内运行代码，不把本机用户名/skill路径写死。

`prepare_editor_session.py`保留`--model`单页入口；`--allow-copy`启用本次复制，省略时仅预览编辑。用户已请求复制则可直接启用，不重复询问。模型/会话兼容标记仍为2.0-test；会话代码、内置结构和依赖摘要保留在生成记录中，不把旧profile当作必需参数。

## 两种绑定方式

默认`unbound`：HTML中的变量只用于设计与本地模拟；复制的数值输入、位按钮、指示灯、仪表、填充和趋势不携带旧工程绑定或编号，数值显示使用常量0占位。粘贴后在MCGS中设置真实变量。网页同时提供`names`模式：用户可填写变量名，生成名称与空缓存，所有未解析的变量编号使用原生未解析标记；MCGS中需要创建同名变量、校验和编译。名称模式不等于已经解析目标工程身份，未获得原厂验证前明确标待验。

导航目标从当前页面集合选择，输出目标名称与未解析ID；MCGS需要解析/核对目标，不能猜测粘贴后的实际窗口ID。新工程、重名和已有窗口的导航解析须实际测试。无真实绑定时不承诺业务动作已运行。

编辑状态与演示状态分开；点选控件不触发按钮、写值或跳转。应用修改后才进入下一次复制；支持逐页草稿、导入导出、撤销重做、还原及数值输入/显示互换。局部复制在MCGS新增对象，用户自行替换旧控件并核对位置。

## 首批12类及可编辑字段

| 类型 | 可编辑字段 |
|---|---|
| 图片 | 位置、尺寸；源SVG保留 |
| 文字 | 内容、位置尺寸、字体大小/字重/颜色、文字边距；应用时统一测量扩框 |
| 数值显示 | 小数位、设计变量名、字体、内置皮肤、显示范围预估、文字边距、位置尺寸；可转输入 |
| 数值输入 | 同上，范围用于MCGS输入上下限；可转显示 |
| 位状态按钮 | 两态文字/颜色、字体、位置尺寸、按1松0/取反、设计变量名 |
| 指示灯 | 位置尺寸、设计变量名；两态图形源独立 |
| 画面跳转 | 文字、字体、位置尺寸、当前页面集合中的目标名称 |
| 报警条 | 背景色、位置尺寸 |
| 报警浏览 | 实时/历史模式、位置尺寸；真实报警源在MCGS设置 |
| 仪表 | 设计变量名、原背景显隐、指针颜色/边距/宽度、位置尺寸；量程0～120 |
| 百分比填充 | 设计变量名、0～100/200/1000、横竖矩形、填充/文字/底色与文字显隐 |
| 实时趋势 | 设计变量名、X/Y主刻线、10/15/20分钟、Y上限100/200/300、曲线1颜色、位置尺寸 |

变量名是标识符，不开放任意脚本/表达式或PLC地址。方形填充、反向、脚本按钮、普通滑块、流动图形与历史趋势不由本轮覆盖。旧控件字段标定记录仅供结构研究，不作为新项目提供供体的前置条件。

文字/数值的“充足/紧凑”边距、自动扩框和范围宽度检查见[统一字体测量](text-layout.md)。应用后若扩框会与邻近元件重叠，保留原预览并指出位置；应调整布局，不反复缩字。数值显示范围只是宽度预估，未生成原厂限幅；复制仍遵循当前未绑定/名称方式。
