# 默认布局与内容容量

适用于新建运行类HMI及未明确布局的大幅改版。客户指定的布局、色调、公共内容和页面范围优先；已有项目局部修改不重新套版。使用实际原生像素宽高组织画布，英寸用于物理可读性和触区判断。

## 顶部状态栏

默认同时规划并在代表页呈现六类内容：logo、公司名称/设备名称、运行状态、通讯状态、用户登录显示、时间。有真实logo/名称时复用；未提供时使用可替换的中性标识/既定默认品牌与设备名，不能虚构客户标识。运行状态、通讯状态和用户身份分别表达，不用一个“正常”代替。各页共用同一框架定义，图标、灯、文字及可操作入口分别建模。

没有真实数据时显示待确认、未连接/待接入、未登录及时间占位；网页演示状态标模拟。身份显示不代表已经实现登录、权限或MCGS脚本。小屏可用图标加短文案、两行排布或清楚的摘要入口，但六类信息不能无记录地消失，字号和触区不得被挤压。

## 报警条与导航边界

报警条默认紧接顶部状态栏，常驻清楚的报警摘要或无活动报警状态。区域用实际矩形登记并检查，不能叠在导航按钮或主区内容上。

- 底部导航：状态栏在顶，报警条在其下，主区位于报警条与底部导航之间。
- 左侧导航：状态栏可横跨顶部；左导航从状态栏下方延伸，报警条仅覆盖右侧业务区。若导航矩形为`[nav_x,nav_y,nav_w,nav_h]`，右侧业务边界为`content_left`，则报警条左边界不小于`nav_x+nav_w`，右边界不超出画布；报警条与左导航矩形不得相交。不要让全宽报警底色覆盖左导航所在列。

这是区域职责，具体宽高随目标尺寸与文字实测调整，不固定百分比或16:9。

## 默认两种布局、四种色调

先看方案分支默认提供左侧导航、底部导航两种实际布局，以及四种实际色调供选择。起点为中性浅色/清蓝、石板深色、暖灰浅色、深海蓝；行业/品牌需要时可调整或新增。布局和色调独立选择：两种布局各可切换四种色调，共八种组合，可在一个HTML中切换，无需维护八套业务代码，也不需要同时建立八个MCGS窗口。

同一尺寸的候选使用同一业务内容与模拟数据，仅改变布局和主题；用户可混搭、修改和自定义。顶部导航保留作明确指定时的扩展，不进入本轮默认两种。直接整套分支沿用首轮范围，助手可采用默认组合先内部核对代表页，不额外强制客户逐项选择或新增审批。

## 大小屏的信息容量

按可用像素空间、物理尺寸、可读性及行业任务决定可见内容，不能只对整个页面等比或非等比放大。先保留必需设备、读数、状态与核心操作；有更多空间时适度增加有依据的对象反馈、设定/反馈对照、趋势/统计或近期事件。次级内容可在小屏收进详情或既有功能页；必需任务仍需保留，不能以小屏为由删需求。

| 常用屏幕 | 内容组织起点（按实际任务调整） |
|---|---|
| 7英寸／800×480 | 核心流程/当前对象、少量关键量与必要操作；次级统计和详情收纳 |
| 10.1英寸／1024×600 | 增加相关设备反馈、设定/反馈或允许条件，仍保持主要阅读顺序 |
| 12.1英寸／1024×768 | 利用额外高度呈现对象明细，以及适用的趋势、统计或事件摘要 |
| 15.6英寸／1920×1080 | 利用宽高扩展工艺场景、设备分组和关联信息；避免把小屏的少量卡片单纯放大铺满 |

其他三种已支持分辨率按相同原则规划；不把上述常用组合当成所有型号的英寸换算。没有相关数据或任务依据时，不为填满大屏编造指标、阈值和工艺，也不强行加入所有模块。内容增减只针对可见信息组织；新增/删除约定页面仍按实际范围处理。

在内容计划记录“核心保留、次级收纳、大屏增加”的模块及去向；代表页按该目标尺寸制作并检查。现有网页没有整页自动重排功能，助手需在项目源调整布局后重建会话。现有方向示例渲染器仍是有限槽位的样板，不能将它的固定内容数误写为所有尺寸的内容容量算法。

## 制作与核对

继续使用“复用模板资产 → 一份项目源 → 代表页验证 → 展开全套”。代表页核对六类顶部内容、报警条和导航互不遮挡、两种布局/四种色调可选，以及内容容量符合目标屏幕。控件、字体边界、结构生成、网页模拟与原厂行为分别记录。默认设计规则不证明未知数据接口、鉴权或实体屏幕已验证。
