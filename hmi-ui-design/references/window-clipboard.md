# 内置窗口结构与批量复制

V2.11 test5按[七种原生分辨率](resolution-adaptation.md)从当前模型生成窗口和控件坐标。内置1024×600默认结构仍作为中性序列化基础，生成时更新窗口尺寸字段，并不限制最终画布为600高。粘贴目标工程须匹配设计规格；更换工程规格前另存副本，避免已保存窗口随之缩放。

V2.10直接用内置默认窗口结构和当前页面模型生成窗口包。不要求原厂窗口捕获、MCP路径或项目模板文件。默认结构含文档前缀、21项窗口属性、空事件尾和窗口后缀；不携带原工程保护数据、脚本、公共页引用或分配剩余。该中性化新窗口分支须单独做原厂验收，不能沿用旧供体批次的保存通过记录。

`MCGS_DRAW_OBJ_PRO1`用于复制当前画布控件；`MCGS_WND_USER_PRO1`用于完整窗口，粘贴到MCGS工程工作台的用户窗口列表。两者都新增对象，不直接写MCP。1～6页为已实现的会话范围。

页面集合`hmi-ui-editor-pages/2.0-test`显式登记安全ASCII id、唯一name、模型路径或完整模型。每页模型revision独立，草稿/撤销隔离。窗口名与画面内标题分别修改，未应用属性阻止复制；生成当前实际勾选页面和修改结果，不重放固定页面二进制。

控件先逐类生成，再分窗建立独立CArchive类/对象映射，核对完整帧和边界、窗口名/临时标识及未改设置。临时标识只描述复制包内对象，不声称等于目标工程最终运行ID。导航输出目标名称和未解析标记，粘贴后的关联须由MCGS核对。

记录当次模型、补丁、图片、内存结构检查、完整剪贴板回读与待绑定信息。原厂显示、保存、组态、编译和运行分别记录，不互相替代。HTML预览阶段即可复制，无需流程3切图输出。
