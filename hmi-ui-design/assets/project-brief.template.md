## 正式切图与最终输出前检查

- [ ] C1/C2/C3评审以HTML承载，未提前渲染页面或组件PNG，也未用静态图包装代替交互页面。

- [ ] C1参数及页面总数已由客户确认，确认对象为当前版本。
- [ ] C2最新代表页HTML的布局和色调已由客户确认。
- [ ] C3约定数量的全套交互HTML已由客户确认；实际页数/ID与清单一致。
- [ ] 受改动影响的旧确认已失效，相关最新版本已重新确认。
- [ ] 客户确认依据是真实回复；文件生成、默认高亮和工具检查未被当作确认。
- [ ] C3已确认HTML的全部可见图形与必要状态均已登记，含人形/装饰图标、独立指示灯及组件子层。
- [ ] 原生实现、仅交矢量或静态背景合并例外有逐项规格/父资产关系及客户确认；动态灯态未合入静态背景。
- [ ] 正式切片与最终输出仅在以上项均满足后开始。

方向样例与全套交互HTML是前置评审成果，可以先交客户；正式切片、生产PNG及最终交付压缩包不得提前制作。
