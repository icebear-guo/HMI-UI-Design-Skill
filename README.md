# HMI UI Design Skill V2.11

工业HMI设计技能：用弹窗帮助新手确认屏幕、行业设备和制作范围，从复用资产与一份项目源生成可编辑的HTML预览，并直接复制MCGS原生控件或完整窗口。作者：工控北极熊（抖音）。

## 下载与启动

从[Releases](https://github.com/icebear-guo/HMI-UI-Design-Skill/releases/latest)下载`hmi-ui-design-v2.11.0.zip`，解压后将整个`hmi-ui-design`文件夹安装到宿主的技能目录。新开任务调用`$hmi-ui-design`即可进入引导，无需另写项目提示词；仅安装文件本身不会自动开始对话。

检查`SKILL.md`元数据为`version: 2.11.0`、`release_channel: stable`、`revision: v211-stable-20261110`。Codex的界面显示名为HMI UI V2.11。保留旧版本和项目，已生成项目内的旧运行代码不会随安装自动升级。

## 默认制作流程

**复用模板资产 → 一份项目源 → 代表页验证 → 展开全套。**

- 首轮弹窗提供7英寸/800×480、10.1英寸/1024×600、12.1英寸/1024×768、15.6英寸/1920×1080四组常用屏幕选项，保留自填规格或型号。
- 同轮询问行业/设备，以及先看总览布局色调，还是直接制作整套。
- 基础五页为运行总览、手动操作、参数设置、报警记录、IO监控；六页增加设备维护，可自定义。
- 先看方案默认提供左侧/底部两种导航和四种独立色调，可混搭和修改。
- 顶部默认包含logo、公司/设备名称、运行状态、通讯状态、用户登录显示、时间。报警条位于其下，左导航时避开侧栏。
- 主区随屏幕空间和任务调整可见内容，大屏增加相关信息，小屏收纳次级内容。当前没有整页自动重排功能。

## 编辑与MCGS复制

使用同一当前模型完成预览、局部编辑和复制。可复制选中控件、当前页控件或1～6个完整窗口，无需先完成最终切图。新项目使用内置中性结构，不要求MCP文件、外部供体或另一份工程技能。

支持12类已实现字段：图片、文字、数值显示、数值输入、位状态按钮、指示灯、画面跳转、报警条、实时/历史报警浏览、仪表、百分比填充、实时趋势。具体可编辑属性及边界见[局部编辑说明](hmi-ui-design/references/local-editor.md)。

默认未绑定真实工程变量，数值可能显示0、输入为空；名称模式保留用户变量名，等待MCGS解析与核对。网页模拟逻辑不会自动变成PLC或MCGS脚本，用户登录显示不等于真实鉴权已完成。

原生路径支持Windows、McgsPro3.5.1.6963及以下七种尺寸：480×272、800×480、800×600、1024×600、1024×768、1366×768、1920×1080。更改MCGS工程屏幕规格前先另存副本，旧窗口可能随之缩放。MCGS仅使用原生复制粘贴；通用素材可单独输出。

## 环境

复制助手使用Windows、Python3.12+和Pillow；不依赖Jet数据库或MCGS工程读取环境。弹窗使用宿主真实提供的交互工具，没有该工具时会报告缺项。浏览器检查、批量素材渲染等按需使用已有Node.js、浏览器及相关依赖，运行要求见对应工具文档。

## 验证范围

V2.11基于逐步验证的字体工具、12类内置结构、七种分辨率样例及默认布局更新发布。默认布局在四种常用分辨率完成32项逻辑及17项真实浏览器检查。不同阶段的检查不重复合计为本轮新测试，详见[发布验证记录](RELEASE_VALIDATION.json)。

原厂样例显示、保存回读、组态检测、编译、运行和实体屏幕分别记录；有限样例不证明所有字体、属性或实际业务均通过。多模型引导执行仍需在实际新任务检验。安装包保留既有内部schema和校验标识，以维持结构兼容，不能自行改名或修改内置二进制字段。

`examples/`、`comparisons/`、旧`tests/`及1.06接口记录保留作历史资料，不作为V2.11当前MCGS出口或本轮测试结果。当前使用方法以本README和技能入口为准。
